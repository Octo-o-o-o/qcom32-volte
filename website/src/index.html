03 / TECHNICAL COMPARISON与参考项目 qualcomm-volte-enabler 的逐层实测对比。

和参考项目的区别：
从单字节脚本到完整 32 位通话栈。

ikimi615/qualcomm-volte-enabler 为黑莓 KEY2（骁龙 660 原厂安卓 8.1）提供了宝贵的 /dev/diag 启发，但在高通 32 位平台 + Android 11 上存在五个维度的代际断层。

技术维度 qualcomm-volte-enabler（黑莓 KEY2 参考项目） 本项目 qcom32-volte（高通 32 位 Android 11 通用栈）
目标平台与架构边界 骁龙 660（SDM660，64 位 arm64-v8a），原厂 Android 8.1 已内置高通闭源 ims.apk 框架。 高通 32 位平台（MSM8974，armeabi-v7a），补齐 LineageOS 18.1（Android 11）完全缺失的现代 ImsService 框架层。
/dev/diag 内核协议 打包 64 位预编译 efs_Write，在 32 位系统无法运行；其指针式 ioctl 在 MSM8974 内核返回 EINVAL (-22)，且 MEMORY_DEVICE_MODE 会拦截 EFS 读写。 自研开源 32 位纯 C pp_regconfig_provision_v6（549 项单测断言），适配 MSM8974 标量值传递 ioctl、sequence16+errno32 头与 CRC-16 校验。
基带 EFS 写入深度 仅将 /nv/item_files/ims/IMS_enable 单字节改为 01。在 Passport 真机实测（1.61/1.62/1.81）中，单改此项仍报 CAUSE_CODE 54、完全无法注册。 解压 11.7MB Q6ZIP 基带固件逆向定位根因：协同配置 54 项 EFS/DS（405B 动态 PCO qp_ims_reg_config + 789B IPV4V6 profile4 + 独立 DCM 模式）。
Android 通话与来电显示 无任何 Android 端代码（文档提及的 qcril.db 与开机脚本在仓库 4 个脚本中均未实现）。 从零实现通用 Qcom32VolteIms.apk v2.4（rild_ims0 Protobuf 引擎、持久化 CarrierConfig、修正 3GPP CLIP→OIR 极性反转与 TOA=145 国际前缀，彻底解决“未知来电”）。
Root 前提与备份回滚 依赖刷入 Magisk；auto_enable_volte.sh 无修改前备份、读失败仍强写、无回滚程序。 免刷 Magisk（支持 LineageOS 原生 adb root 调试 + 免 su 屏幕状态面板 App）；强制先备份原值，内置 --rollback-all 跨重启实机验证。
完整代码级审计证据与里程碑对照已公开归档。 阅读完整技术对比报告

打开完整使用指南
必须要给手机刷 Magisk 吗？

不需要！LineageOS 18.1 系统设置里的「开发者选项 → Root 调试（Rooted debugging）」原生支持通过 USB 取得 adb root（UID 0）。使用 Windows 桌面一键版或跨平台 CLI 即可完成一次性激活，激活后拔掉数据线、重启与换 SIM 卡均自动生效，且 Qcom32VolteManager 无需 Magisk 即可在手机屏幕显示完整实时状态。

早期已安装旧包名 org.passport.volteims 的设备如何升级？

完全自动！运行 v1.1.0-r1 的桌面一键版或 CLI 时，工具会自动清理旧包残留、平滑迁移至新通用包名 org.octolab.qcom32ims（v2.4）并重新绑定持久化 CarrierConfig。

来电显示正常吗？为什么早期方案会显示“未知号码”？

已完整修复。Qcom32VolteIms v2.4 修正了 3GPP CLIP（0=允许显示）与 Android ImsCallProfile.OIR（2=允许显示）的常量极性反转，并在来电建链后推送 callSessionUpdated 与国际 + 号格式，实测来电号码与通讯录匹配完全正常。

如果不想用了，能彻底恢复到修改前的基带状态吗？

可以。每次激活前工具都会先导出基带原始快照；点击桌面工具的「恢复出厂基带配置并卸载」（或运行 volte_ctl.py rollback），会将全部 54 项 EFS 条目回写/删除至出厂状态、执行 EFS_SYNC、卸载 APK 并正常重启验证。

支持紧急呼叫（110/119/120/911）吗？

本开源项目属于实验性经典硬件救援方案，未经过运营商或紧急呼叫中心（E911/IMS Emergency PDN）认证。请勿将修改后的老手机作为唯一的紧急求救联络工具。
