硬件级安全校验

只认 wolverine + CRC16 校验

执行前强制核对 ro.product.device=wolverine、SELinux=Enforcing 与 SIM 就绪状态；每包 DIAG EFS 读写均校验 CCITT CRC-16。

零权限污染

保护 120 项系统电话权限

在 Android 11 上共享 android.uid.phone 若声明额外权限会导致系统电话崩溃；本桥接 APK 严格保持零权限声明并通过字节码门禁验证。

彻底解耦电脑

一次激活，手机独立运行

使用 3 参数持久化 overrideConfig(..., true) 与开机广播自启。激活完成后拔掉 USB、日常开关机均由手机本地独立恢复 VoLTE。

03 / TECHNICAL COMPARISON与参考项目 qualcomm-volte-enabler 的逐层实测对比。

和参考项目的区别：
从单字节脚本到全栈实现。

ikimi615/qualcomm-volte-enabler 为黑莓 KEY2（骁龙 660 原厂安卓 8.1）提供了很好的 /dev/diag 启发，但在骁龙 801 + Android 11 上存在五个维度的代际鸿沟。

技术维度 qualcomm-volte-enabler（黑莓 KEY2 参考项目） 本项目 passport-android11-volte（Passport Android 11）
目标平台与指令集 骁龙 660（SDM660，64 位 arm64-v8a），原厂 Android 8.1 已自带高通现代 ims.apk 框架栈。 骁龙 801（MSM8974，32 位 armeabi-v7a），LineageOS 18.1（Android 11）完全缺失任何 ImsService。
/dev/diag 内核协议 打包 64 位预编译 efs_Write，在 32 位系统直接无法执行；其指针式 ioctl 在 MSM8974 内核返回 EINVAL (-22)，且 MEMORY_DEVICE_MODE 会拦截 EFS 读写。 自研开源 32 位纯 C pp_regconfig_provision_v6（549 项单测断言），适配 MSM8974 标量值传递 ioctl、sequence16+errno32 头与 CRC-16 校验。
基带 EFS 写入深度 仅将 /nv/item_files/ims/IMS_enable 单字节改为 01。在 Passport 真机实测（1.61/1.62/1.81）中，单改此项仍报 CAUSE_CODE 54、完全无法注册。 解压 11.7MB Q6ZIP 基带固件逆向定位根因：协同配置 54 项 EFS/DS（405B qp_ims_reg_config + 789B IPV4V6 profile4 + 保持 ims_hybrid_enable 缺省以启用独立 DCM）。
Android 通话与来电显示 无任何 Android 端代码（文档提及的 qcril.db 与开机脚本在仓库 4 个脚本中均未实现）。 从零实现 PassportVolteIms.apk v2.3（rild_ims0 Protobuf 引擎、持久化 CarrierConfig、修正 3GPP CLIP→OIR 极性反转与 TOA=145 国际前缀，彻底解决“未知来电”）。
Root 前提与备份回滚 依赖刷入 Magisk；auto_enable_volte.sh 无修改前备份、读失败仍强写、无回滚程序。 免刷 Magisk（支持 LineageOS 原生 adb root 调试，同时提供 Magisk 伴侣 App）；强制先备份原值，内置 --rollback-all 跨重启实机验证。
完整代码级审计证据与里程碑对照已公开归档。 阅读完整技术对比报告

07 / FAQ动手前最常遇到的几个问题。

常见问题
与安全边界。

打开完整使用指南
必须要给手机刷 Magisk 吗？

不需要！LineageOS 18.1 系统设置里的「开发者选项 → Root 调试（Rooted debugging）」原生支持通过 USB 取得 adb root（UID 0）。使用 Windows 桌面一键版或跨平台 CLI 即可完成一次性激活，激活后拔掉数据线、重启手机依然自动生效。如果你已经刷了 Magisk，也可以选用手机端管理 App。

激活后会耗电变快或影响 Wi-Fi / 4G 上网吗？

不会。基带侧使用的是高通骁龙 801 硬件协处理器自带的独立 IMS PDN（profile4），与普通上网 4G APN（default）并行独立；Android 侧服务仅在注册状态变化或来电/去电时驱动事件回调，无后台轮询。

来电显示正常吗？为什么早期方案会显示“未知号码”？

已完整修复。PassportVolteIms v2.3 修正了 3GPP CLIP（0=允许显示）与 Android ImsCallProfile.OIR（2=允许显示）的常量极性反转，并在来电建链后推送 callSessionUpdated 与国际 + 号格式，实测 nump=1 来电号码与通讯录匹配完全正常。

如果不想用了，能彻底恢复到修改前的基带状态吗？

可以。每次激活前工具都会先导出基带原始快照；点击桌面工具的「恢复出厂基带配置并卸载」（或运行 volte_ctl.py rollback），会将全部 54 项 EFS 条目回写/清理至出厂状态、执行 EFS_SYNC、卸载 APK 并正常重启验证。

支持紧急呼叫（110/119/120/911）吗？

本开源项目属于实验性老设备救援方案，未经过运营商或紧急呼叫中心（E911/IMS Emergency PDN）认证。请勿将修改后的老手机作为唯一的紧急求救联络工具。
