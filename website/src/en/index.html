03 / TECHNICAL COMPARISONCode-level & live-hardware audit vs ikimi615/qualcomm-volte-enabler.

How this differs from
qualcomm-volte-enabler.

ikimi615/qualcomm-volte-enabler inspired our initial /dev/diag exploration on BlackBerry KEY2 (SDM660 Android 8.1), but bridging MSM8974 on Android 11 required solving five fundamental gaps.

Dimension qualcomm-volte-enabler (KEY2 Reference) passport-android11-volte (This Project)
SoC, ABI & OS Snapdragon 660 (arm64-v8a), stock Android 8.1 already ships Qualcomm’s modern ims.apk stack. Snapdragon 801 (MSM8974, 32-bit armeabi-v7a), LineageOS 18.1 (Android 11) has zero ImsService.
/dev/diag Contract Ships prebuilt 64-bit efs_Write binary; pointer-style ioctl returns EINVAL (-22) on MSM8974 kernel, and MEMORY_DEVICE_MODE blocks EFS ops. Open-source 32-bit C pp_regconfig_provision_v6 (549 unit assertions) using scalar ioctl, sequence16+errno32 headers, and CCITT CRC-16.
Baseband EFS Scope Writes 1 byte (IMS_enable=01). Live-tested on Passport (1.61/1.62/1.81): still fails with CAUSE_CODE 54 READ_FAILED & NOT_REGISTERED. Decompressed 11.7MB Q6ZIP Hexagon firmware to build Stage 6A: 54 coordinated EFS/DS items (405B qp_ims_reg_config + 789B IPV4V6 profile4 + standalone DCM).
Android Stack & Caller ID Zero Android app code (README mentions of qcril.db and boot scripts are unimplemented in its 4 shell scripts). Full PassportVolteIms.apk v2.3 (rild_ims0 protobuf engine, persistent CarrierConfig, 3GPP CLIP→OIR + TOA=145 Caller ID fix).
Root & Rollback Safety Requires Magisk; auto_enable_volte.sh performs no backup, writes even after read failure, and has no rollback tool. No Magisk required (works over LineageOS Rooted Debugging + optional Magisk app), mandatory pre-backup, and verified --rollback-all.

Open Complete Guide
Do I need to install Magisk?

No! LineageOS 18.1 includes built-in “Rooted debugging” under Developer Options, allowing our Windows EXE or cross-platform CLI to run adb root over USB once. After activation, unplug USB and reboot freely. If you already use Magisk, you can also manage everything on-device with PassportVolteManager.apk.

Does incoming Caller ID work properly?

Yes. PassportVolteIms v2.3 translates 3GPP CLIP presentation values into Android’s ImsCallProfile.OIR_* constants, normalizes TOA=145 international numbers, and pushes callSessionUpdated so incoming numbers match Contacts cleanly.

Can I completely revert my modem EFS back to factory state?

Yes. Every deployment saves a local pre-activation snapshot first, and “Restore Factory Modem EFS & Uninstall” (or volte_ctl.py rollback) restores all 54 EFS items, runs EFS_SYNC, uninstalls the APK, and reboots cleanly.

Can I rely on this for emergency calls (911/112/110)?

No. This is an experimental community hardware-preservation project and has not undergone emergency services certification (E911 / IMS Emergency PDN). Do not rely on modified legacy devices as your sole emergency phone.
