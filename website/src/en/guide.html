SETUP & INTEGRATION GUIDE · v1.0.0-r1

From USB connection to unplugged 4G voice calls

Follow each stage in order: verify prerequisites → enable Rooted Debugging → run one of the four activation workflows → verify real incoming and outgoing calls with USB unplugged.

01. Prerequisites & Safety Boundaries

  1. Target Device & OS: BlackBerry Passport (SQW100-1 / SQW100-3 / SQW100-4, codename wolverine) running LineageOS 18.1-UNOFFICIAL-wseries (Android 11 / API 30, SELinux Enforcing). Non-wolverine devices are rejected automatically.
  2. Provisioned SIM: Insert an active 4G/5G USIM with VoLTE enabled on your carrier account and confirm LTE data attaches normally.
  3. Idle Phone State: Ensure no call is active, battery is above 30%, and use a reliable USB data cable.
Data Safety: Activation only provisions the 54 targeted IMS modem items (after saving a local backup) and installs the bridge APK—it does not wipe user data. Never rely on experimental legacy modifications as your sole emergency (911/112) device.

02. Enable LineageOS 18.1 USB & Rooted Debugging

When using Method 1 (Windows EXE) or Method 3 (Portable CLI), Magisk is not required:

  1. Open Settings → About phone and tap Build number 7 times to unlock Developer Options.
  2. Open Settings → System → Advanced → Developer options.
  3. Turn ON Android debugging (USB debugging).
  4. Turn ON Rooted debugging on the same screen.
  5. Connect via USB and accept the “Allow USB debugging?” RSA fingerprint dialog on the phone.

03. Method 1: Windows Desktop One-Click EXE (Recommended)

  1. Download and launch passport-android11-volte-1.0.0-r1-windows-x64.exe.
  2. Verify your Passport serial appears in the “ADB Device” selector and click “1. Check Status (Read-Only)”.
  3. Click “2. Backup & Activate VoLTE (Recommended)” and confirm.
  4. The tool switches to adb root, saves a pre-deployment EFS snapshot under %LOCALAPPDATA%\passport-android11-volte\backups\, provisions Stage 6A + EFS_SYNC, installs PassportVolteIms.apk v2.3 with persistent CarrierConfig, reboots normally, and polls until volte_stack_healthy: true.

04. Method 2: On-Device Companion App (For Magisk Users)

  1. Install PassportVolteManager-1.0.0-r1.apk on your Passport (directly on the phone or via the desktop button “Install Mobile Companion App”).
  2. Tap “Refresh Status” anytime to inspect IMS service & QMI_IMSA registration (works even without root).
  3. If Magisk (su) is installed, tap “Activate / Repair Native VoLTE (Root)” and grant the Magisk superuser prompt to run SHA-256-verified backup, Stage 6A provisioning, APK installation, and normal reboot right on the device.

05. Method 3: macOS / Linux / Cross-Platform Portable ZIP

Extract passport-android11-volte-1.0.0-r1-portable.zip (requires Python 3.9+ and adb):

python3 cli/volte_ctl.py self-test
python3 cli/volte_ctl.py status
python3 cli/volte_ctl.py deploy
# Or launch the cross-platform Tkinter GUI:
python3 cli/gui.py

06. Method 4: LineageOS 18.1 ROM Integration & MSM8974 Porting

ROM builders can include PassportVolteIms directly in /system/priv-app/ using rom-integration/Android.bp and device-passport-volte.mk:

mkdir -p packages/apps/PassportVolteIms
cp -r src/android-ims-service/* src/qmi-imsa-probe rom-integration/Android.bp packages/apps/PassportVolteIms/
# Add to device/blackberry/wolverine/device.mk:
$(call inherit-product, packages/apps/PassportVolteIms/device-passport-volte.mk)

Because Android ROM zips do not overwrite Qualcomm’s dedicated modem EFS partition, Stage 6A modem provisioning must still be run once per physical handset. For porting notes covering OnePlus One, Xperia Z2/Z3, Galaxy S5, Mi 4, LG G3, and HTC One M8, see MSM8974_PORTING_GUIDE.md.

07. SIM Swapping & Multi-Carrier Notes

Stage 6A modem EFS settings use the standard ims APN and dynamic PCO (mode=0) and remain stored across SIM swaps. Because Android’s CarrierConfig is keyed per SIM subId, after inserting a different VoLTE SIM simply click “Upgrade Bridge APK Only” (or run python3 cli/volte_ctl.py upgrade-apk) to bind CarrierConfig to the new SIM.

08. Live Call Acceptance Checklist

  1. Unplug the USB cable so the phone operates completely standalone;
  2. Place an outgoing call in the stock Dialer: confirm clear two-way audio and verify the status bar stays on LTE / 4G throughout the call;
  3. Receive an incoming call: confirm ringing, accurate Caller ID display (not “Unknown”), and clean hangup;
  4. Reboot the phone normally, wait ~30 seconds after unlock, and place another call to confirm hands-free boot recovery.

09. Full Factory Modem EFS Rollback

Click “Restore Factory Modem EFS & Uninstall” in the desktop GUI or run:

python3 cli/volte_ctl.py rollback

10. Verify SHA-256 Checksums

# Windows PowerShell:
Get-FileHash "$HOME\Downloads\passport-android11-volte-1.0.0-r1-windows-x64.exe" -Algorithm SHA256

# macOS / Linux:
shasum -a 256 ~/Downloads/passport-android11-volte-1.0.0-r1-portable.zip
