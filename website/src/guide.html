SETUP & INTEGRATION GUIDE · v1.2.7-r1

从检查设备到安装与回滚

仅一台联通 wolverine 完整实测。

⚠️ 紧急呼叫不支持、未认证；请备另一部手机。 LTE-only 网络可能无法拨通 110/112/911。写入基带有风险：请先独立备份 EFS 并存到手机之外，风险自负；检查日志不是完整备份，固定回滚不保证原值恢复。请自行备份 modemst1、modemst2、fsg。v1.2.4-r1 及更早版本仍允许对未经验证版本一键写入，且 v1.2.4-r1 / v1.2.5-r1 会误拒 .DI.4.0.1 运行时基带；请升级至 v1.2.7-r1。v1.2.4 的预检和自动回滚与 v1.2.6 的基带识别修正仅经离线/模拟验证，未在故障真机上验证。

01. 前提条件与已验证设备 Profile

  1. 一台 SQW100-1 wolverine 验证；oslo、wichita、keian、wseries、windermere 默认只读，回滚保留。
  2. 源码部署还须检查旧 IMS 守护进程，运行时基带包含 DI.4.0.1（如 .DI.4.0.1-00158-M8974AAAAANAZM-1）和 AAAAANAZM，Root 下固件 build_id 为 AAB982（免 Root 只读体检遇 SELinux 限制将标记待 Root 复核，不误判基带不兼容）；回滚不受部署门禁阻断。重启后符合无信号条件时会尝试固定回滚，不能保证恢复原值或信号；此防护仅经离线/模拟验证。
  3. SIM 卡要求：已插入开通了 VoLTE 高清语音业务的 4G/5G USIM 卡，且处于机身射频支持的 LTE 频段内并正常驻留 LTE。
  4. 保持空闲状态：执行写入与重启前，请确认当前没有正在进行的通话，电量建议高于 30%，并使用可靠的数据线连接电脑。
独立备份 EFS 并移出手机；检查日志不是可恢复的完整备份。

02. 开启 LineageOS 18.1 的 USB 调试与 Root 调试

使用电脑端激活方式（方式一或方式三）完全不需要刷入 Magisk，只需打开系统自带的开发者开关：

  1. 进入 设置 → 关于手机，连续点击 7 次最下方的 版本号（Build number） 启用开发者选项。
  2. 返回进入 设置 → 系统 → 高级 → 开发者选项。
  3. 开启 Android 调试（USB 调试），并在同页面开启 Root 调试（Rooted debugging）。
  4. 连接电脑，在手机弹出的「允许 USB 调试吗？」对话框中勾选一律允许并点击确定。（注：激活完成后可随时关闭「Root 调试」，通话栈在标准 SELinux Enforcing 下 独立运行（仅在所测设备验证）。）

03. 方式一：Windows 桌面一键激活工具（最推荐）

  1. 下载 qcom32-volte-1.2.7-r1-windows-x64.exe 并双击运行（无需安装 Python 或 ADB）。
  2. 确认顶部「ADB 设备」下拉框已识别到手机序列号，点击 「1. 只读检查状态」（非 Passport 的高通 32 位手机可点击 「多机型识别与只读适配体检（AI + GitHub）」 查看 4 道门禁体检并一键复制 AI 提示词）。
  3. v1.2.7-r1 匹配 wolverine 后显示按钮 「2. 激活 VoLTE（wolverine）」；检查日志并非可恢复的 EFS 原值备份。
  4. 程序保存 EFS 检查日志和哈希，执行配置写入、安装与重启；日志不能恢复全部原值。
  5. （推荐顺手点一下）点击 「安装手机端管理 App」，将伴侣应用推送到手机桌面，可在手机屏幕查看状态。

04. 方式二：手机端独立状态与管理 App

安装 Qcom32VolteManager-1.2.7-r1.apk（桌面图标名称 Qcom32 VoLTE）：

  1. 无 Magisk 场景（免 su 实时状态面板 + 多机型只读体检）：打开应用点击「刷新实时状态」，通过只读 content://org.octolab.qcom32ims.status 接口读取当前 SIM 运营商、rild_ims0、QMI_IMSA 与系统注册状态；若安装在其他高通 32 位机型上，可点击「多机型识别与只读适配体检」生成零写入诊断报告并复制 AI 提示词。
  2. 手机端源码仅允许 wolverine 激活；其他 Passport 版本可只读或回滚。

05. 方式三：macOS / Linux / 跨平台便携包（CLI & GUI）

下载并解压 qcom32-volte-1.2.7-r1-portable.zip（内置已编译签名的 ARM32 工具、双 APK 与 devices/ Profile 库，仅需 Python 3.9+ 与 adb）：

# 1. 离线单元测试自检 / 查看内置 32 位机型目录
python3 cli/volte_ctl.py self-test
python3 cli/volte_ctl.py list-models

# 2. 只读检查当前手机状态，或对任意 32 位机型执行 100% 只读适配体检
python3 cli/volte_ctl.py status
python3 cli/volte_ctl.py inspect-device

# 3. 独立备份后写入 Stage 6A 并检查注册（wolverine）
python3 cli/volte_ctl.py deploy

# 4. 顺手安装手机端实时状态/管理伴侣 App
python3 cli/volte_ctl.py install-manager

# 5. 或启动跨平台桌面图形界面
python3 cli/gui.py

SIM 已识别但无信号

先运行 Windows 的只读体检，或执行 python3 cli/volte_ctl.py inspect-device。如果 SIM 已加载、语音和数据均无服务且运行时基带为空，工具会引导检查基带运行模式与固件来源。工厂测试模式是已实测的一种原因；退出工厂模式属于独立维修。

鬼触过滤和只在顶部听筒无声的故障也走独立维修。听筒故障可以先对照普通音频与 VoLTE 的听筒和免提输出。

银色版 Passport（oslo）

一台银色版用定向修订的 LineageOS 18.1 20251205、AAB982 和联通 46001 完成了呼入、呼出。CLI 可用 prepare-oslo-rom 检查本机；确认自身 EFS 备份和 Recovery 后，再用 prepare-oslo-rom --apply 处理匹配的旧 IMS 配置。激活仍须走 CLI 实验双确认。

06. 方式四：LineageOS 18.1 ROM 源码集成与 32 位新机型适配

面向 100% 免费纯公益社区 ROM 维护者，rom-integration/ 目录提供了通用 Soong Android.bp 与 device-qcom32-volte.mk（编译进 /system_ext/priv-app/，保留 LICENSE、COMMERCIAL-LICENSE.md 与 Required Notice: 即可免费集成）：

# 在 LineageOS 18.1 源码树中引入通用通话栈服务：
mkdir -p packages/services/Qcom32VolteIms
cp -r src/android-ims-service/src src/android-ims-service/res src/android-ims-service/AndroidManifest.xml \
      src/qmi-imsa-probe rom-integration/Android.bp rom-integration/device-qcom32-volte.mk \
      packages/services/Qcom32VolteIms/

# 在目标 32 位高通设备的 device.mk 末尾加入：
$(call inherit-product, packages/services/Qcom32VolteIms/device-qcom32-volte.mk)

注意：ROM 刷机包不会改写高通独立基带分区（Modem EFS），每台实体机首次仍需执行一次基带 EFS 供给。付费/商业刷机包、有偿远程代刷及预刷 VoLTE 二手机销售需事先取得 商业授权（octoooo@octoooo.com）。为一加 1、小米 4、索尼 Z2/Z3、三星 S5 等同代 MSM8974 机型新增 devices/<id>/profile.json 的完整规范，请查阅 MSM8974_PORTING_GUIDE.md 与 devices/README.md。

07. 换卡与验证范围

  1. 换卡效果取决于具体 SIM、运营商及网络，不能保证自动注册或通话。
  2. 联通 46001 在一台 wolverine 和一台实验 oslo 完成通话验证；电信 46003/46011 已验证 LTE 和 IMS，一台 46011 免提双向有声、听筒无声，EPS-only 防掉线 149 秒无掉线。移动未测；FDD B3/B8 仅理论，机身无 TDD B38–41。IMS 短信未实现；紧急呼叫、VoWiFi、视频、补充业务和非中国运营商不支持或未测试。

08. 真实通话验收清单（必做）

  1. 拔掉 USB 数据线，打开手机桌面的 Qcom32 VoLTE 确认显示绿字「VoLTE 通话栈已激活并注册就绪」；
  2. 用系统自带拨号器拨打外部电话，确认双方声音清晰，且顶部信号栏全程保持 LTE / 4G；
  3. 用外部手机回拨，确认响铃正常、来电号码完整显示（非“未知”）、挂断干脆；
  4. 正常重启一次手机，等待约 20–30 秒后再次拨打电话确认开机自愈生效。

09. 固定基带清理与卸载

连接电脑点击桌面工具的 「执行固定基带清理并卸载」，或执行：

python3 cli/volte_ctl.py rollback

固定回滚写入 00 并删除指定项目，不从检查日志恢复本机原值，不能保证出厂状态。若 /dev/diag 因非兼容基带无法启动而回滚失败，请先恢复您独立保存的 modemst1 / modemst2 / fsg 备份，或先刷入原版 BlackBerry Android AAB982 NON-HLOS.bin 后再回滚。

10. 校验下载文件 SHA-256

# Windows PowerShell:
Get-FileHash "$HOME\Downloads\qcom32-volte-1.2.7-r1-windows-x64.exe" -Algorithm SHA256

# macOS / Linux:
shasum -a 256 ~/Downloads/qcom32-volte-1.2.7-r1-portable.zip
