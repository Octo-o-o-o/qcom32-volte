# 交付形态与换卡边界

本源码可见项目（PolyForm Noncommercial 1.0.0 + 商业授权）提供 Windows 桌面工具、Android 管理端、便携 CLI/GUI 和 ROM 集成。四种方式的真实端到端验证仅在一台 Passport SQW100-1 `wolverine`、联通 46001 完成；其他设备不能据此推断。

基带 `mode=0` 和 Android `CarrierConfigBootstrapReceiver` 设计用于动态发现与换卡后的配置更新，但不同运营商、SIM、网络和硬件仍需分别验证。电信 46003/46011 仅验证 LTE 驻留及 IMS 注册，通话未测；EPS-only 防掉线观察 149 秒无掉线。移动未测：FDD B3/B8 是理论可能，Passport 无 TDD B38–41。非中国运营商未测；不得承诺通话、回落或移动数据在所有情况下可用。

IMS 短信未实现；紧急呼叫不支持且未获认证。VoWiFi、视频通话与呼叫转移、USSD、UT 等补充业务不支持或未测试。不要使用紧急号码验收，且应保留另一部手机用于紧急呼叫。

本工具自动保存 EFS 检查日志和哈希，不保存可完整恢复的原始备份；写入前请独立备份并将备份存放在手机之外。固定回滚动作不保证恢复每台手机的原值。机型门禁与命令见 [安装和回滚](INSTALL_AND_ROLLBACK.md)。v1.2.4-r1 及更早版本尚无本次新增门禁，请升级至 v1.2.5-r1，未验证设备勿运行旧版写入操作。
